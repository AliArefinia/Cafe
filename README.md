# Jalās Cafe (جلاس) - QR Code Ordering App

React frontend starter for Jalās Cafe using a mobile-first PWA layout.

Features included:
- Arabic-first RTL layout
- Bottom navigation bar for app-like ordering flow
- Table selection, menu, cart, and order confirmation screens
- Menu categories and item grid with bilingual labels
- PWA manifest and service worker registration

Run the frontend with:

```bash
npm install
npm run dev
```
